# 以勒服饰 JIREH APPAREL

静态服装品牌网站，包含 43 个款式与 66 张服装实拍图片。

## GitHub Pages

将本目录内容上传到 GitHub 仓库根目录，然后在 Settings → Pages 中选择 Deploy from a branch，指定 main 分支的 / (root)。

无需安装依赖或构建。首页为 index.html。

## 内容

- 首页、材质专题与定制服务
- 按季节、材质、领型筛选，支持款号搜索
- 产品图片、参数、尺码选择及浏览器本地收藏
- 链接到品牌现有的下单与订单查询系统

服装图片与产品信息来自以勒服饰提供的云展网画册。
